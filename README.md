# coursesdownloader
O script em Python criado automatiza todo o download e organização de cursos no Telegram. Lendo o histórico de mensagens, ele converte textos estruturais em pastas no seu HD e baixa todos os arquivos, como vídeos, imagens e PDFs, diretamente para os módulos certos. Isso restaura a estrutura original do curso com extrema praticidade e muita rapidez.
